# UniGrade – Electronic Gradebook

This is a final project inspired by the Librus electronic gradebook. It was created for the **Interactive Web Development** course taught by **Rafał Kotas** at **IFE**.

The application is a simple university gradebook. Students can view their subjects and grades, while lecturers can create subjects and assign grades to students.

The project uses **Angular**, **Spring Boot**, **Hibernate/JPA**, **PostgreSQL**, and **JWT authentication**.
